# Blaze's Partners
Shared partnership dashboard for Blaze's Pressure Washing.
Plain HTML/JS, no build step. Hosted on GitHub Pages.
- Demo mode: no keys in `config.js` -> data saved on this device only.
- Live mode: Supabase keys in `config.js` -> email/password login, shared + realtime, only partner emails allowed. See SETUP.md.
- No private data or money rules live in this code; they're entered in the app and stored in the database.
